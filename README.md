# Keeep Website

Astro-site voor de Keeep website en blog.

## Lokaal ontwikkelen

```bash
npm install
npm run dev
```

Open daarna de lokale Astro URL die in de terminal verschijnt.

## Structuur

- `src/pages/`: websitepagina's en blogroutes
- `src/layouts/`: gedeelde layouts
- `src/styles/`: globale styling
- `public/legacy/`: bestaande losse HTML-pagina's als referentie/archief

De repo blijft private. De uiteindelijke website kan later wel publiek gedeployed worden.
